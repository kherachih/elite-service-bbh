# 🚀 Elite Service BBH — Modern Web Platform

> **Site officiel moderne, interactif et ultra-rapide pour Elite Service BBH.**  
> Studio d'ingénierie logicielle, architecture cloud ERP, design d'interfaces de luxe et croissance numérique.

---

## ✨ Points Forts & Fonctionnalités

* 💎 **Direction Artistique Dark Luxury :** Palette Obsidian (#07090e) avec accents vifs Neon Magenta (`#ec4899`), Violet Luminescent (`#c026d3`) et Coral Électrique (`#f97316`).
* 📱 **Lecteur Natif Instagram Reels (Style TikTok / Reels) :**
  * Modale plein écran intégrée avec défilement vertical fluide.
  * Navigation tactile (touch swipe), molette de souris (wheel) et drag à la souris.
  * Boutons d'interaction animés (Like, Partage direct vers Instagram, mute/unmute audio individuel).
* ⚡ **Moteur Mobile Réactif & Défilement Haute Performance :**
  * Optimisé pour écrans tactiles iOS & Android sans conflit de débordement.
  * Intégration de [Lenis Smooth Scroll](https://github.com/darkroomengineering/lenis) avec synchronisation GSAP ScrollTrigger.
  * Watchdog dynamique garantissant un défilement 100% débloqué sur tous les appareils.
* 🛡️ **Autonomie & Fiabilité Locale :**
  * Dépendances clés (jQuery, Reels MP4, médias) hébergées localement dans `/public/assets` pour un chargement instantané sans dépendance à des CDN externes.
* 💼 **Sections Complètes :**
  * **Hero Section** avec typographie percutante et logo signature.
  * **Sponsoring & Projets** avec carrousel de cartes interactif.
  * **Solutions ERP & Cloud** avec visuels haute résolution.
  * **Formulaire de Contact** réactif avec retour instantané.

## 🛠️ Stack Technique

* **Build Tool :** [Vite 8](https://vitejs.dev/)
* **Animations & Défilement :** [GSAP 3](https://greensock.com/), [ScrollTrigger](https://greensock.com/scrolltrigger/), [Lenis](https://lenis.darkroom.engineering/)
* **Styles :** CSS3 Moderne, Grid / Flexbox fluide, variables CSS, typographie adaptative (`clamp()`)
* **Médias :** Vidéos MP4 natives optimisées, images WebP / SVG haute définition

## 🚀 Démarrage Rapide

### Prérequis
* Node.js (version 18 ou supérieure recommandée)
* npm ou yarn / pnpm

### Installation

```bash
# Cloner le dépôt
git clone https://github.com/kherachih/elite-service-bbh.git
cd elite-service-bbh

# Installer les dépendances
npm install
```

### Développement

```bash
npm run dev
```
Ouvrez [http://localhost:5173](http://localhost:5173) dans votre navigateur.

### Build Production

```bash
npm run build
```
Les fichiers prêts pour le déploiement sont générés dans le dossier `/dist`.

### Prévisualisation de Production

```bash
npm run preview
```
